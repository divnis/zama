How it works (brief): If you type text, the client computes a SHA-256 fingerprint and converts a small slice into a numeric fingerprint. That number is masked with a large random value and sent to the server. The server only sees masked numbers and returns the masked sum. The client subtracts its masks locally to reveal the final (simulated) result. This avoids sending raw text to the server.
Tip: click Use safe example to try demo without typing. This is NOT real FHE — when you are ready for a real FHE demo we can replace the server with Concrete/TFHE-rs and the client with a WASM crypto module.
